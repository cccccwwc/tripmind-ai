TripMind AI 是一个面向真实旅行场景的智能规划 Agent。用户无需填写复杂表单，只要在对话中说明目的地、日期、预算和偏好。

系统会持续合并信息，生成结构化 Planning Brief。日期与天数冲突时主动提醒，只有用户确认后才启动规划，避免需求不完整导致错误结果。

随后，Tavily 从公开攻略中整理带来源的推荐地点，由用户选择。长期旅行画像保存偏好、避雷项和原话证据，并支持审批、编辑、忘记和单次覆盖。

后端使用 FastAPI 与 LangGraph。景点、天气、酒店节点并行执行，高德接口负责真实数据，模型负责需求理解与路线取舍。任务立即返回 job id，并通过 SSE 推送进度。

可靠性节点会检查 POI ID、城市、行政区、经纬度、开放状态、来源和置信度。不合格地点自动返回景点节点补搜，再生成当天路线。

结果页按时间顺序展示每日景点、餐饮、酒店、交通和预算。地图只标记通过坐标校验的地点；远期天气没有可靠预报时明确降级，而不是编造温度。

用户可保存历史规划，系统只统计真正进入时间轴的地点，并可把未完成地点带入下一次旅行。

工程层支持取消、重试、断线重连、中断恢复、SQLite 检查点和长期记忆。当前包含五十五项后端测试、二十二项前端测试，以及旅行 Agent 离线评测集。

生产环境采用多阶段 Docker 构建，将 Vue 和 FastAPI 部署为同源服务。TripMind AI 完成了从需求理解、真实工具调用，到数据校验和持续记忆的 Agent 产品闭环。
